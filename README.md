# HR Employee Attrition Analysis Using SQL

## 📌 Project Overview

This project analyzes employee attrition using SQL.

The dataset contains 1,470 employee records and includes employee demographics, job details, salary, satisfaction, work experience, business travel, overtime, and attrition status.

## 🎯 Project Objective

The objective of this project is to identify patterns related to employee attrition and understand the factors associated with employees leaving the organization.

## 🛠️ Tools & Technologies

- MySQL
- SQL

## 🔍 Analysis Performed

- Employee attrition analysis
- Department-wise attrition
- Job role-wise attrition
- Job level-wise attrition
- Age group-wise attrition
- Gender-wise attrition
- Marital status analysis
- Overtime vs attrition
- Business travel vs attrition
- Years at company vs attrition
- Job satisfaction vs attrition
- Monthly income analysis
- Education field vs attrition

## 🧹 Data Cleaning & Validation
